# Shadawa Pastoralist Women Media Empowerment Analysis

**Author:** Abdullahi Isah
**Date:** September 2026
**Tools:** Python (Pandas, Matplotlib)

---

## Overview

This project analyzes media access among pastoralist women in Shadawa, Dawakin Kudu Local Government Area, Kano State. The analysis is based on Round 1 data from the IDRC-SPARC-FUDECO research project on gender equality, empowerment, and social inclusion of pastoralist women.

## Key Findings

- **Radio is the gateway:** Radio is the most used medium (62%) and the only channel with significant reach among women (50%).
- **Telephone gender gap:** There is a 64.7 percentage point gap in telephone access between men (78.6%) and women (13.9%).
- **Digital divide:** Only 2.8% of women have internet access, and only 16.7% have heard of social media.
- **Women trail men on every channel:** As a share of each group, women are behind men on every channel (e.g., radio 50.0% vs 92.9%).

## Recommendations

1. **Prioritize Radio:** Design the media empowerment project around radio programming in Fulfulde and Hausa.
2. **Address Telephone Access:** Explore community phone-sharing models or subsidized handsets for women.
3. **Digital Literacy Component:** Include basic digital literacy training, but do not rely on it as the primary channel.
4. **Engage Men as Allies:** Include men in awareness and buy-in sessions.

## Data Source

This analysis is based on data from the **IDRC-SPARC-FUDECO Research Project** (Round 1, 2022), Kano State, Nigeria. Data used with permission from the project.

**Note:** The sample is small (N=50, including only 14 men). These findings should be treated as indicative, not definitive.
